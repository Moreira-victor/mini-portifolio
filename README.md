## 📖 Sobre

Este projeto é um portfólio pessoal minimalista desenvolvido para apresentar informações profissionais, projetos e habilidades de forma clean e moderna. O design prioriza a simplicidade e a usabilidade, com foco na responsividade para funcionar perfeitamente em qualquer dispositivo.

- ✅ Design responsivo e adaptável
- ✅ Layout limpo e minimalista

- ✅ Animações sutis para melhor experiência

## 🚀 Como Usar

### Clonar o Repositório

```bash
git clone https://github.com/Moreira-victor/mini-portifolio.git
cd mini-portifolio
```

### Abrir o Projeto

1. Abra o arquivo `index.html` em seu navegador
2. Ou use um servidor local:

```bash
# Usando Python
python -m http.server 8000

# Usando Node.js (http-server)
npx http-server
```

### Hospedar no GitHub Pages

1. Vá em Settings do repositório
2. Selecione "Pages"
3. Escolha a branch `main` e a pasta `/root`
4. O site estará disponível em `https://username.github.io/mini-portifolio`

## 🎨 Personalização

### Alterar Informações Pessoais

Edite o arquivo `index.html` e modifique:

- Nome e título
- Biografia
- Seção de habilidades
- Projetos apresentados
- Informações de contato

### Alterar Cores e Estilos

As cores e estilos podem ser personalizados no CSS dentro do próprio HTML ou em arquivos CSS separados na pasta `src/css/`.

### Adicionar Projetos

Para adicionar novos projetos, adicione items na seção de projetos do HTML seguindo o padrão existente.
